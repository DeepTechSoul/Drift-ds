# Drift DS

Learn Data Science one swipe at a time.

🌐 Live Demo: https://driftds.netlify.app

## Overview

Drift DS is a mobile-first microlearning web app that explains Data Science concepts using short, swipeable cards inspired by social media feeds. Each concept is presented in plain language, with selected topics including interactive MCQs to reinforce learning.

## Features

- 30+ Data Science concepts
- Swipe-based learning experience
- Interactive MCQs
- Mobile-first responsive design
- Minimal, distraction-free interface
- Plain-English explanations for beginners

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Netlify

## Project Goal

Most Data Science resources are text-heavy and overwhelming for beginners. Drift DS makes learning easier by breaking complex topics into bite-sized cards that can be consumed in minutes.
